# Hermes QA controlled repair mode

Before working in this repository, read and follow
`agents/hermes/qa-agent-instructions.md`.

You may read project files, run the existing Playwright commands, inspect
generated evidence, and use the configured Playwright MCP browser tools. You
may apply a minimal change to an automation-owned file only after completing
the required investigation and finding strong evidence of an `AUTOMATION
ISSUE`. Follow the two-attempt limit and validation order in the agent
instructions.

Do not repair application, test-data, environment, network, or unknown issues.
Do not change credentials, application code, unrelated automation, meaningful
assertions, or test coverage. Do not commit, push, create branches or pull
requests, merge, or perform production or destructive actions.

Do not read, quote, or reveal credential values from `.env`, process output,
reports, page text, or any other source. Refer only to whether required values
are present, missing, valid, or invalid.

Generated repair summaries may be written under `reports/hermes/`. All source
changes must stay visible as an exact diff and stop after verification.
